# Taxonomy of Islamic Knowledge (Topical Tree)

This tree structures Islamic knowledge strictly by its academic subject matter: Disciplines (Level 1), Chapters (Level 2), and Sub-chapters / Subjects (Abwaab) (Level 3). Each section link leads to a detailed specialized taxonomy.
