Narrated Ibn `Umar:

Allah's Messenger (ﷺ) said: Islam is based on (the following) five (principles):

  • To testify that none has the right to be worshipped but Allah and Muhammad is Allah's Messenger.
  • To offer the (compulsory congregational) prayers dutifully and perfectly.
  • To pay Zakat (i.e. obligatory charity) .
  • To perform Hajj. (i.e. Pilgrimage to Mecca)
  • To observe fast during the month of Ramadan.
info
بُنِيَ (buniya): Passive perfect verb, meaning "was built" or "is based upon". Root: ب ن ي.

IslamResearch leverages a modern, highly optimized technical stack to deliver a seamless IDE experience in the browser. Zero-latency text rendering and complex layout management.

Tailwind CSS v4 daisyUI v5 Geist Typeface Material Symbols 
import { Workspace, SplitPane } from '@islamresearch/ide';

const config = {
  theme: 'obsidian-dark',
  layout: 'split-view',
  activeModules: ['morphology', 'tafsir'],
  typography: {
    base: 'Geist',
    arabic: 'KFGQPC Uthman Taha Naskh'
  }
};

export default function ScholarInterface() {
  return (
    <Workspace config={config}>
      <SplitPane primary="source" secondary="intelligence" />
    </Workspace>
  );
}
