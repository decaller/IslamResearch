Al-Baqarah

Madani • Ayah 2

ذَٰلِكَ ٱلْكِتَـٰبُ لَا رَيْبَ ۛ فِيهِ ۛ هُدًۭى لِّلْمُتَّقِينَ

Translation (Sahih International)

This is the Book about which there is no doubt, a guidance for those conscious of Allah.
