# Design System Document

## Visual Identity & Tone
This design system utilizes an **Expressive** dark-mode aesthetic, balancing technical precision with a sophisticated, professional color palette. The interface is designed for high readability and functional elegance, utilizing a unified typography set to create a seamless user experience.

## Typography
The system relies on a single, high-performance typeface to ensure consistency across all levels of the hierarchy.

- **Headline Font:** Inter
- **Body Font:** Inter
- **Label Font:** Inter

The use of **Inter** across all roles provides a modern, clean, and neutral foundation that allows the expressive color palette to take center stage.

## Color Palette
The color strategy is optimized for a dark environment, using muted tones for primary surfaces and vibrant accents for interactive elements.

- **Primary Color:** #5a77ab (Steel Blue) - Used for primary actions and key brand moments.
- **Secondary Color:** #657c70 (Sage Grey) - Supporting UI elements and secondary interactive states.
- **Tertiary Color:** #108859 (Emerald) - Highlights, success states, and decorative accents.
- **Neutral Color:** #707788 (Slate) - Backgrounds, borders, and non-chromatic surface layers.

## Layout & Geometry
The interface uses a balanced approach to spacing and corner treatments to maintain a professional yet approachable feel.

- **Roundedness:** Moderate (Level 2). UI elements feature standard rounded corners, providing a modern look that feels softer than sharp edges but more structured than pill shapes.
- **Spacing:** Normal (Level 2). The layout maintains standard gutters and padding, ensuring optimal information density without feeling cramped or overly sparse.

## Interaction Principles
As a dark-mode first system, emphasis is placed on contrast and depth. Elements should use subtle shifts in the neutral and primary tones to indicate elevation and interactive state changes. The "Expressive" variant allows for more daring use of the Tertiary emerald color in animations and micro-interactions.
